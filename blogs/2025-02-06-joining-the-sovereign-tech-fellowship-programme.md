I’m happy to announce that I have been selected for the one-year pilot of the Sovereign Tech Fellowship programme of the Sovereign Tech Agency. The fellowship programme will support maintenance of Nominatim, Photon, osm2pgsql and pyosmium over the next year. Participating in an open-source software project like Nominatim or Photon is not just about the implementation of fancy new features or clever algorithms to improve performance or the user experience.
