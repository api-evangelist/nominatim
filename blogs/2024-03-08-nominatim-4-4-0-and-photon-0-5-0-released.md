We are happy to announce that this week new versions of Nominatim and its ElasticSearch frontend Photon have been released. Version 4.4.0 of Nominatim brings many bug fixes and performance improvements for the new Python frontend, which was introduced in version 4.3.0. It can now be considered stable and has become the frontend recommended to be used for new installations.
