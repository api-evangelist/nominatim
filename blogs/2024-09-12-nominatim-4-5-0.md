We are happy to announce the release of version 4.5.0 of Nominatim. This is a transition release, helping you to prepare the move towards the upcoming Nominatim 5.0 , which will be a pure Python application. The most important change in this release is that Nominatim is now available via pypi.org and can be installed with a simple pip install nominatim-db nominatim-api .
